# Next / Prev Transport Buttons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the transport bar's `⏭` button fall back to the next folder neighbor when the queue is empty, and add a `⏮` button that either restarts the current file (if > 3 s in) or plays the previous folder neighbor.

**Architecture:** Two new SQL helpers on `LibraryDB` find adjacent files alphabetically within the same `(library_id, parent_dir)` group. A new transport button calls a `_play_prev` handler; the existing `⏭` is rewired to a new `_play_next` that prefers the queue and falls back to the folder-neighbor query. The pre-existing `_play_next(files)` method (a queue-prepend action from the tree right-click) is renamed to `_queue_play_next` to free the short name for the transport handler.

**Tech Stack:** Python 3.14, PyQt6, libVLC via `python3-vlc`, SQLite + FTS5, pytest.

Spec: [`docs/superpowers/specs/2026-05-13-next-prev-design.md`](../specs/2026-05-13-next-prev-design.md).

```python
def next_file_in_folder(self, library_id: int, parent_dir: str,
                        filename: str) -> FileRow | None:
    cols = """id, library_id, path, parent_dir, filename, ext, size, mtime, duration,
              title, year, series, season, episode, artist, album, track"""
    row = self.conn.execute(
        f"""SELECT {cols} FROM files
            WHERE library_id=? AND parent_dir=? AND filename > ?
            ORDER BY filename ASC LIMIT 1""",
        (library_id, parent_dir, filename),
    ).fetchone()
    return FileRow(*row) if row else None

def prev_file_in_folder(self, library_id: int, parent_dir: str,
                        filename: str) -> FileRow | None:
    cols = """id, library_id, path, parent_dir, filename, ext, size, mtime, duration,
              title, year, series, season, episode, artist, album, track"""
    row = self.conn.execute(
        f"""SELECT {cols} FROM files
            WHERE library_id=? AND parent_dir=? AND filename < ?
            ORDER BY filename DESC LIMIT 1""",
        (library_id, parent_dir, filename),
    ).fetchone()
    return FileRow(*row) if row else None
```

Replace it with the new `_play_next` and `_play_prev` methods:

```python
def _play_next(self):
    """Transport ⏭: queue first, else next folder neighbor."""
    f = self.queue_model.take_next()
    self._persist_queue()
    if f:
        self._play(f)
        return
    cur = self.current_file
    if cur is None or cur.library_id is None:
        return
    nxt = self.db.next_file_in_folder(cur.library_id, cur.parent_dir, cur.filename)
    if nxt:
        self._play(nxt)

def _play_prev(self):
    """Transport ⏮: restart current if > 3s in, else previous folder neighbor."""
    cur = self.current_file
    if cur is None:
        return
    if self.video.get_time() > 3000:
        self.video.set_position(0.0)
        return
    if cur.library_id is None:
        return
    prv = self.db.prev_file_in_folder(cur.library_id, cur.parent_dir, cur.filename)
    if prv:
        self._play(prv)
```
